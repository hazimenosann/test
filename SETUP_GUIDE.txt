============================================================
  Catawiki AIボット - セットアップガイド
============================================================

このボットは以下のことを自動で行います：
  - 5分ごとにCatawikiの新着メッセージを確認
  - AIが人間らしい返信案を自動生成
  - LINEにメッセージと返信案を日本語で通知
  - LINEで「返信を送る」をタップするとCatawikiに送信
  - 日本語で返信を入力すると自動翻訳して送信

config.json に6つの値を入力する必要があります。
それぞれの取得方法を以下に説明します。


------------------------------------------------------------
1. Catawiki のメールアドレス
------------------------------------------------------------
Catawiki にログインするときのメールアドレスを入力します。
例: "email": "yourname@gmail.com"


------------------------------------------------------------
2. Anthropic API キー（AI返信に使用）
------------------------------------------------------------
1. https://console.anthropic.com/ にアクセス
2. アカウントを作成（無料）
3. 左メニューの「API Keys」をクリック
4. 「Create Key」をクリック
5. 表示されたキーをコピー（sk-ant- から始まる）
6. config.json に貼り付け

費用の目安：月に時計を2〜3本販売する程度なら月額約1〜5円程度。


------------------------------------------------------------
3. LINE チャンネルアクセストークン
------------------------------------------------------------
1. https://developers.line.biz/ にアクセス
2. LINEアカウントでログイン
3. 「新規プロバイダー作成」をクリックし、任意の名前を入力
4. 「Messaging API チャンネルを作成」をクリック
5. 必要項目（チャンネル名、説明など）を入力
6. 作成後、「Messaging API」タブを開く
7. 下にスクロールして「チャンネルアクセストークン」を探す
8. 「発行」ボタンをクリックしてトークンを生成
9. 表示された長いトークンをコピーして config.json に貼り付け

例: "line_token": "abc123xyz..."


------------------------------------------------------------
4. LINE ユーザーID
------------------------------------------------------------
これはボットのIDではなく、あなた自身のLINEユーザーIDです。

1. LINE Developersコンソールで作成したチャンネルを開く
2. 「基本設定」タブをクリック
3. 下にスクロールして「あなたのユーザーID」を探す
4. U から始まる文字列が表示される
   例: U1234567890abcdef1234567890abcdef
5. コピーして config.json に貼り付け

例: "line_user_id": "Uabcdef1234567890"


------------------------------------------------------------
5. ngrok 認証トークン
------------------------------------------------------------
ngrok とは、自宅のPCに外部からアクセスできるURLを作成する
サービスです。LINEがあなたのPCにメッセージを届けるために必要です。

1. https://ngrok.com/ にアクセス
2. アカウントを作成（無料）
3. ログイン後、左メニューの「Your Authtoken」を開く
4. トークンをコピーして config.json に貼り付け

例: "ngrok_auth_token": "2abc123..."


------------------------------------------------------------
6. ngrok 固定ドメイン（★重要：一度設定すれば永久に変わらない）
------------------------------------------------------------
無料で取得できる固定URLです。これを設定すると、PCを再起動しても
LINEのWebhook URLが変わらないため、一度設定するだけで完了します。

取得方法：
1. ブラウザで以下のURLに直接アクセス：
   https://dashboard.ngrok.com/domains
2. 「+ New Domain」ボタンをクリック
3. 「Free」または「Static Domain」を選択
4. 自動生成されたドメインをコピー
   例: certain-fox-honestly.ngrok-free.app
5. config.json の "ngrok_domain" に貼り付け
   （https:// は不要。ドメイン名だけ入力）

※ 上記ページを開いてもドメインが作れない場合：
   ページ上部に「Upgrade」案内がある → 無料プランで1つだけ作れます。
   すでにドメインが表示されている → それをそのままコピーして使ってください。

例: "ngrok_domain": "certain-fox-honestly.ngrok-free.app"


------------------------------------------------------------
  最終的な config.json の内容（例）
------------------------------------------------------------
{
  "email": "yourname@gmail.com",
  "anthropic_api_key": "sk-ant-abc123...",
  "line_token": "XYZ123longtoken...",
  "line_user_id": "U1234567890abcdef",
  "ngrok_auth_token": "2abc123yourtokenhere",
  "ngrok_domain": "certain-fox-honestly.ngrok-free.app"
}


------------------------------------------------------------
  初回起動後に必要なLINEの設定（一度だけ）
------------------------------------------------------------
ボットを初めて起動した後、LINE DevelopersコンソールでWebhookを
設定する必要があります。これは一度だけでOKです。

1. ボットを起動する（起動.bat をダブルクリック）
2. ターミナルに表示される「Webhook URL:」の行をコピー
   例: https://certain-fox-honestly.ngrok-free.app/webhook
3. LINE Developersコンソール → チャンネル → 「Messaging API」タブ
4. 「Webhook URL」欄に貼り付けて「更新」をクリック
5. 「検証」をクリック → 「Success」が出ればOK
6. 「Webhookの利用」をオンにする

固定ドメインを設定した場合、このURLは永久に変わりません。
次回からは起動するだけで自動的に接続されます。


------------------------------------------------------------
  LINEボットを友だちに追加（一度だけ）
------------------------------------------------------------
1. LINE Developersコンソール → 「Messaging API」タブ
2. 「ボット情報」のQRコードをスキャン
3. スマートフォンのLINEで友だち追加
