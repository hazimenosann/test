============================================================
  Catawiki AIボット - セットアップガイド
============================================================

このボットは以下のことを自動で行います：
  - 5分ごとにCatawikiの新着メッセージを確認
  - AIが人間らしい返信案を自動生成
  - LINEにメッセージと返信案を日本語で通知
  - LINEで「返信を送る」をタップするとCatawikiに送信
  - 日本語で返信を入力すると自動翻訳して送信

config.json に5つの値を入力する必要があります。
それぞれの取得方法を以下に説明します。


------------------------------------------------------------
1. Catawiki のメールアドレス
------------------------------------------------------------
Catawiki にログインするときのメールアドレスを入力します。
例: "email": "yourname@gmail.com"


------------------------------------------------------------
2. Anthropic API キー（AI返信に使用）
------------------------------------------------------------
1. https://console.anthropic.com/ にアクセス
2. アカウントを作成（無料）
3. 左メニューの「API Keys」をクリック
4. 「Create Key」をクリック
5. 表示されたキーをコピー（sk-ant- から始まる）
6. config.json に貼り付け

費用の目安：月に時計を2〜3本販売する程度なら月額約1〜5円程度。


------------------------------------------------------------
3. LINE チャンネルアクセストークン
------------------------------------------------------------
1. https://developers.line.biz/ にアクセス
2. LINEアカウントでログイン
3. 「新規プロバイダー作成」をクリックし、任意の名前を入力
4. 「Messaging API チャンネルを作成」をクリック
5. 必要項目（チャンネル名、説明など）を入力
6. 作成後、「Messaging API」タブを開く
7. 下にスクロールして「チャンネルアクセストークン」を探す
8. 「発行」ボタンをクリックしてトークンを生成
9. 表示された長いトークンをコピーして config.json に貼り付け

例: "line_token": "abc123xyz..."


------------------------------------------------------------
4. LINE ユーザーID
------------------------------------------------------------
これはボットのIDではなく、あなた自身のLINEユーザーIDです。

1. LINE Developersコンソールで作成したチャンネルを開く
2. 「基本設定」タブをクリック
3. 下にスクロールして「あなたのユーザーID」を探す
4. U から始まる文字列が表示される
   例: U1234567890abcdef1234567890abcdef
5. コピーして config.json に貼り付け

例: "line_user_id": "Uabcdef1234567890"


------------------------------------------------------------
5. ngrok 認証トークン（LINEのWebhook用公開URLを作成）
------------------------------------------------------------
ngrok とは、自宅のPCに外部からアクセスできるURLを一時的に
作成するサービスです。LINEがあなたのPCにメッセージを届けるために
必要です（無料で使えます）。

1. https://ngrok.com/ にアクセス
2. アカウントを作成（無料）
3. ログイン後、ダッシュボードの「Your Authtoken」を開く
4. トークンをコピーして config.json に貼り付け

例: "ngrok_auth_token": "2abc123..."

注意：ボット動作中はPCの電源を入れたままにしてください。


------------------------------------------------------------
  最終的な config.json の内容（例）
------------------------------------------------------------
{
  "email": "yourname@gmail.com",
  "anthropic_api_key": "sk-ant-abc123...",
  "line_token": "XYZ123longtoken...",
  "line_user_id": "U1234567890abcdef",
  "ngrok_auth_token": "2abc123yourtokenhere"
}


------------------------------------------------------------
  初回起動後に必要なLINEの設定
------------------------------------------------------------
ボットを初めて起動した後、LINE DevelopersコンソールでWebhookを
有効にする必要があります。

1. LINE Developersコンソールでチャンネルを開く
2. 「Messaging API」タブをクリック
3. 「Webhook設定」の「Webhookの利用」をオンにする
4. 「検証」をクリックして正常に動作するか確認

また、LINEボットを友だちに追加する必要があります：
1. 「Messaging API」タブを開く
2. 「ボット情報」のQRコードを探す
3. スマートフォンのLINEアプリでQRコードをスキャンして友だち追加
